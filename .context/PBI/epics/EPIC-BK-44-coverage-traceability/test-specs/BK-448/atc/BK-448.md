## 4. Assertions Split

### Fixed (inside ATC)

- Captured traceability response status is 404.
- Captured traceability response message equals "User story not found." (mechanism pending §6.1).
- `[data-testid="traceability-chain-view"]` is not visible.
- Zero `[data-testid^="traceability-ac-"]` and zero `[data-testid^="traceability-atc-row-"]` nodes exist.

### Test-level (in test file)

Scenario 1 (nonexistent story) calls the ATC once — no flow-level comparison needed within the test itself; the "identical response across both rows" claim from the Gherkin outline is satisfied by both test-file entries calling the SAME ATC with different `targetStoryId` inputs and getting the same fixed-assertion pass, not by an explicit cross-test diff (the TC-identity/EP-merge doctrine treats "same ATC, same assertions, different input" as the mechanism that proves the outline's own point).
