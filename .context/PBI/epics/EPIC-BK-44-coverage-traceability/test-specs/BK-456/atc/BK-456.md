- Exactly one ATC row renders inside the AC card (`toHaveCount(1)`) — the boundary-specific check.
- That ATC row's title, layer badge, Test name, and Run status pill are all non-empty.

None beyond the ATC call — single-scenario boundary check, no flow-level comparison (same shape as BK-445).
