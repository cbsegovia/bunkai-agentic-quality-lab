## 4. Assertions Split

### Fixed (inside ATC)

- Chain-view root becomes visible within the ATC's timeout.
- Every AC card renders with a non-empty title.
- Every ATC row renders with a non-empty title and a recognized layer value (UI/API/Unit).
- Every Test name renders non-empty.
- Every latest-run status pill renders with one of the recognized statuses (pass/fail/blocked/skipped/aborted/running).
- Every Defect block renders id + title + status, non-empty.

### Test-level (in test file)

None beyond the ATC call — this is a single-scenario happy-path test with no flow comparison (contrast BK-50's `expectSnapshotUnchangedAfterMutation`, which does need a T0-vs-T1 test-level comparison; BK-445 does not).
