## 4. Assertions Split

- Fixed (ATC): the four assertions above.
- Test level: precondition `getOpenBugs(fixtureId).open_count === 0` BEFORE navigating (fail loud with a message if not); after the ATC, `getOpenBugs(fixtureId)` returns `open_count 0` and `by_severity` `{P1:0,P2:0,P3:0,P4:0}` (explicit workspace id; bearer allowed to read it, ADR-0006).

## 5. Code Template

```typescript
const FIXTURE_WORKSPACE = 'BK-258 QA Fixture';

test('BK-1096: should show 0 and the Nothing outstanding message without severity chips given a workspace with no open bug', async ({ test: fixture }) => {
  const { api, ui } = fixture;
  fixture.clearAuthToken();
  const [, me] = await api.auth.getCurrentUser();
  const fixtureWs = me.workspaces.find(w => w.name === FIXTURE_WORKSPACE);
  expect(fixtureWs, `fixture workspace "${FIXTURE_WORKSPACE}" missing on this environment`).toBeDefined();
  const [, before] = await api.openBugs.getOpenBugs(fixtureWs!.id);
  expect(before.open_count, 'precondition: fixture workspace must hold no open bug in an active module').toBe(0);
  await ui.home.selectWorkspace(fixtureWs!.id);
  await ui.home.open();
  await ui.home.showsNothingOutstandingWithoutSeverityChips();
  const [, oracle] = await api.openBugs.getOpenBugs(fixtureWs!.id);
  expect(oracle).toMatchObject({ open_count: 0, by_severity: { P1: 0, P2: 0, P3: 0, P4: 0 } });
});
```
