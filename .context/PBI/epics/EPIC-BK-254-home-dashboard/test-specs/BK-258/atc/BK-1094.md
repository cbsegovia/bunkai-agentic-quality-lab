## 1. Test Case Summary

| Name | Objective | Precondition | Acceptance Criteria |
|------|-----------|--------------|---------------------|
| `showsCountedBugTotalAndMinorChip` | After one P3 bug is moved forward to a status, the Home card total and P3 chip equal the baseline plus the delta of that status | Owner signed in (cookie identity); baseline read from the API (>= 1 open bug); one P3 bug in a fresh active module moved to the row's status | open, in_progress: total and P3 +1. resolved, closed: total and P3 +0. API `open_statuses` = ["open","in_progress"]; API `open_count` = card total |

## 5. Code Template

```typescript
const ROWS = [
  { status: 'open', advances: [], delta: 1 },
  { status: 'in_progress', advances: ['in_progress'], delta: 1 },
  { status: 'resolved', advances: ['in_progress', 'resolved'], delta: 0 },
  { status: 'closed', advances: ['in_progress', 'resolved', 'closed'], delta: 0 },
] as const;

for (const row of ROWS) {
  test(`BK-1094: should ${row.delta ? 'count' : 'exclude'} a P3 bug in status ${row.status} in the Home open bugs total`, async ({ test: fixture }) => {
    const { api, ui } = fixture;
    fixture.clearAuthToken();
    const [, me] = await api.auth.getCurrentUser();
    const workspaceId = me.active_workspace_id!;
    const [, base] = await api.openBugs.getOpenBugs(workspaceId);
    expect(base.open_count, 'precondition: shared workspace needs >= 1 open bug so chips render').toBeGreaterThan(0);
    const projectId = (await api.projects.findProjectByName({ workspaceId, name: QA_PROJECT })) ?? /* generate once */;
    const [, mod] = await api.projects.createModuleSuccessfully({ projectId, payload: api.data.createModule() });
    try {
      const [, filed] = await api.bugs.createBugSuccessfully({ project_id: projectId, module_id: mod.module.id, ...api.data.createBug({ severity: 'P3' }) });
      for (const status of row.advances) await api.bugs.advanceBugStatusSuccessfully({ bugId: filed.bug.id, status });
      await ui.home.open();
      await ui.home.showsCountedBugTotalAndMinorChip({ total: base.open_count + row.delta, P3: base.by_severity.P3 + row.delta });
      const [, oracle] = await api.openBugs.getOpenBugs(workspaceId);
      expect(oracle.open_statuses).toEqual(['open', 'in_progress']);
      expect(oracle.open_count).toBe(base.open_count + row.delta);
      expect(oracle.by_severity.P3).toBe(base.by_severity.P3 + row.delta);
    } finally { /* archive module in try/catch, warn only */ }
  });
}
```
