## 1. Test Case Summary

| Name | Objective | Precondition | Acceptance Criteria |

| `showsOpenBugTotalWithSeverityBreakdown` | The Home "Open bugs" card shows the workspace total and one chip per severity, and the total equals the sum of the chips | Signed-in Owner (storageState); baseline read from the API; 5 bugs seeded in an active module: P1 open, P2 open, P2 in_progress, P3 open, P4 in_progress | AC1: total = baseline + 5; chips P1 +1, P2 +2, P3 +1, P4 +1 vs baseline; total = sum of chips; API `open_count` / `by_severity` equal the card |

## 2. ATC Contract

```typescript
export interface OpenBugsCounts { total: number, P1: number, P2: number, P3: number, P4: number }   // tests/data/types.ts

/**
 * ATC: The Home "Open bugs" card shows the expected total and the four
 * severity chips. Navigation is a separate helper (`open()`); this ATC starts
 * on /home.
 *
 * Fixed assertions:
 *  - the skeleton placeholder is gone (toHaveCount(0)) BEFORE any count is read
 *  - the severities container is visible; each chip is visible with its label
 *    (P1 Critical, P2 Major, P3 Minor, P4 Trivial)
 *  - the displayed total equals the sum of the four displayed chip counts
 * Scenario assertions (from `expected`, computed by the test from the baseline):
 *  - displayed total and each chip count equal `expected`
 *
 * @returns the counts actually read off the card (for the API parity check)
 */
@atc('BK-1093')
async showsOpenBugTotalWithSeverityBreakdown(expected: OpenBugsCounts): Promise<OpenBugsCounts>
```

## 4. Assertions Split

### Fixed (inside ATC)

Skeleton detached, severities visible, labels, total = sum of chips.

### Test-level (in test file)

- After the ATC, `getOpenBugs(workspaceId)` equals what the card showed: `open_count === displayed.total` and each `by_severity` value equals its chip.
- Baseline arithmetic (`expected` is built from `baseline` + the seeded matrix).

## 5. Code Template

```typescript
import { expect, test } from '@TestFixture';

const SEEDED = [
  { severity: 'P1', status: 'open' }, { severity: 'P2', status: 'open' },
  { severity: 'P2', status: 'in_progress' }, { severity: 'P3', status: 'open' },
  { severity: 'P4', status: 'in_progress' },
] as const;

test.describe('BK-258: Home open bugs card', { tag: ['@critical'] }, () => {
  test('BK-1093: should show the open bug total with a P1-P4 breakdown that sums to it given open bugs at several severities', async ({ test: fixture }) => {
    const { api, ui } = fixture;
    fixture.clearAuthToken();                       // cookie identity == browser identity
    const [, me] = await api.auth.getCurrentUser();
    const workspaceId = me.active_workspace_id!;
    const [, base] = await api.openBugs.getOpenBugs(workspaceId);

    const [, project] = await api.projects.createProjectSuccessfully(workspaceId, api.data.createProject());
    const [, mod] = await api.projects.createModuleSuccessfully({ projectId: project.project.id, payload: api.data.createModule() });
    try {
      for (const spec of SEEDED) {
        const [, created] = await api.bugs.createBugSuccessfully({ project_id: project.project.id, module_id: mod.module.id, severity: spec.severity, ...api.data.createBug() });
        if (spec.status === 'in_progress') {
          await api.bugs.advanceBugStatusSuccessfully({ bugId: created.bug.id, status: 'in_progress' });
        }
      }
      await ui.home.open();
      const displayed = await ui.home.showsOpenBugTotalWithSeverityBreakdown({
        total: base.open_count + 5,
        P1: base.by_severity.P1 + 1, P2: base.by_severity.P2 + 2,
        P3: base.by_severity.P3 + 1, P4: base.by_severity.P4 + 1,
      });
      const [, oracle] = await api.openBugs.getOpenBugs(workspaceId);
      expect(oracle.open_count).toBe(displayed.total);
      expect(oracle.by_severity).toEqual({ P1: displayed.P1, P2: displayed.P2, P3: displayed.P3, P4: displayed.P4 });
    } finally {
      await api.projects.archiveModuleSuccessfully(mod.module.id);
    }
  });
});
```
